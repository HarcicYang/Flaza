# 群事件播报示例

这个示例插件演示插件如何用 `ctx.before_event` 接管核心内置的群事件提示，
替换为包含成员名和群名上下文的详细灰条通知，同时自行完成必要的成员缓存
写入，避免吞掉事件后丢失状态更新。

## 覆盖事件

- 成员加入群聊
- 成员退出或移出群聊
- 管理员设置/取消
- 成员禁言/全员禁言
- 群名变更

## 原理

- `before_event` 在核心灰条和服务处理器之前执行。
- 插件调用 `storage.members` / `storage.contacts` 更新对应缓存。
- `ctx.notify` 把播报文本写入对应群的聊天流并立即刷新界面。
- 返回 `None` 吞掉原事件，避免内置通用提示重复出现。

## 配置

本示例不需要额外配置；如不希望某个事件被接管，直接从 `on_load` 中删除
对应的 `before_event` 注册即可。
